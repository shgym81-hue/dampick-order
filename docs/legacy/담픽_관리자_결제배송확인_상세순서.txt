담픽 관리자에서 결제·배송 신청 확인하기

==================================================
왜 기존 관리자에 결제·배송이 안 보였나
==================================================

기존 admin.html은 회원·상품·주문·매출 관리 화면입니다.

새 결제·배송 신청은 기존 admin.html 안에 직접 넣은 것이 아니라
payments.html이라는 별도의 관리자 화면으로 추가했습니다.

따라서 기존 관리자 화면에 들어갔다고 해서
결제·배송 내용이 자동으로 아래에 나타나는 구조가 아닙니다.

확인 방법은 두 가지입니다.

방법 1:
payments.html 주소로 직접 접속

방법 2:
기존 admin.html 위쪽에
"결제·배송 관리" 버튼을 추가하고 버튼을 눌러 이동

==================================================
1. GitHub 파일 목록 확인
==================================================

GitHub에서 다음 저장소를 엽니다.

shgym81-hue / dampick-order

저장소 첫 화면 파일 목록에 아래 파일이 있어야 합니다.

admin.html
config.js
index.html
payments.html

payments.html이 없다면 결제·배송 관리자 화면에 들어갈 수 없습니다.

payments.html이 없을 때:

1. Add file
2. Create new file
3. 파일 이름에 payments.html 입력
4. 담픽_payments새파일_복사붙여넣기용.txt 전체 복사
5. GitHub 빈 입력창에 전체 붙여넣기
6. Commit changes
7. 다시 Commit changes

==================================================
2. 직접 접속 주소
==================================================

https://shgym81-hue.github.io/dampick-order/payments.html?v=20260804-payment-admin1

https://shgym81-hue.github.io/dampick-order/admin.html?v=20260804-payment-admin1

저장 직후 404가 나오면 2~5분 기다린 뒤 다시 접속합니다.

==================================================
3. 기존 관리자에서 들어가는 방법
==================================================

1. 기존 admin.html 주소를 엽니다.
2. 기존에 사용하던 관리자 이메일과 비밀번호를 입력합니다.
3. 관리자 로그인을 누릅니다.
4. 로그인 후 화면 위쪽의 "결제·배송 관리" 버튼을 누릅니다.
5. payments.html 화면에서 고객 신청을 확인합니다.

버튼이 아직 없다면
admin_결제배송관리버튼_교체코드.txt의 안내대로
admin.html의 상단 버튼 부분만 교체합니다.

5. 고객 신청이 목록에 나타나는 조건
==================================================

다음 작업이 모두 끝나야 목록에 나타납니다.

1. Supabase SQL Editor에서
   결제·배송 SQL 전체 실행
2. 고객 index.html에서 닉네임 조회
3. 주문 선택
4. 픽업 또는 집 앞 배송 선택
5. 결제방법 선택
6. "결제·수령 방법 신청하기" 버튼 누르기
7. 신청 저장 완료 메시지 확인

고객이 화면에서 배송방법만 선택하고
마지막 신청 버튼을 누르지 않았다면
관리자 목록에는 저장되지 않습니다.

==================================================
6. 화면별 오류 확인
==================================================

A. payments.html 주소에서 404가 나옴

원인:
- GitHub에 payments.html이 없음
- 파일명이 틀림
- 아직 GitHub Pages 반영 전

확인:
- payments.html
- payment.html이 아님
- payments.html.txt가 아님

B. 로그인 화면은 나오지만 로그인이 안 됨

기존 admin.html에서 사용하던
관리자 이메일과 비밀번호를 똑같이 입력합니다.

먼저 admin.html에서 로그인한 뒤
"결제·배송 관리" 버튼을 누르는 방법이 가장 쉽습니다.

C. 로그인했지만 "표시할 신청이 없습니다"라고 나옴

확인:
- 고객이 마지막 신청 버튼을 눌렀는지
- Supabase SQL이 Success로 실행됐는지
- 고객 화면에서 신청번호가 나왔는지

D. checkout_requests 테이블 관련 오류

원인:
Supabase SQL이 실행되지 않았거나 중간에 실패한 것입니다.

처리:
1. Supabase
2. SQL Editor
3. New query
4. 01_담픽_결제배송_업데이트.sql 전체 붙여넣기
5. Run
6. Success 확인

E. 화면이 예전 상태로 보임

주소 끝의 숫자를 바꿔서 접속합니다.

admin.html?v=20260804-101
payments.html?v=20260804-101

또는 브라우저 캐시를 삭제합니다.

7. 실제 시험 순서
==================================================

1. 기존 관리자에서 5,000원 시험 주문 등록

3. 주문 체크

6. 주소와 공동현관 정보 입력
7. 계좌이체 선택
8. 결제·수령 방법 신청하기 누르기
9. 신청번호가 나오는지 확인
10. 기존 관리자 로그인
11. 결제·배송 관리 버튼 누르기
12. 고객 닉네임과 집 앞 배송이 보이는지 확인
13. 결제 완료 처리
14. 배송 준비 처리
15. 배송 완료 처리

==================================================
중요
==================================================

기존 admin.html은 삭제하지 않습니다.
config.js도 삭제하지 않습니다.
payments.html만 추가하고,
admin.html에는 이동 버튼만 추가합니다.
